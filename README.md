# 🐍 Python Data Engineering Basics

A hands-on Python practice repository exploring essential data handling techniques, file formats, web scraping, and database operations.

## 📚 Topics Covered

- **📂 Data Loading & File Handling** — Read and write text files, convert data into CSV format, and explore Pickle serialization.
- **🌐 Web Scraping Basics** — Use `Requests` and `BeautifulSoup` to fetch webpage content and extract HTML elements.
- **⚡ Parquet Files** — Save and load DataFrames in Parquet format and explore column-oriented data storage.
- **🗄️ SQLite Database Operations** — Create databases and tables, insert records, and retrieve data using SQL queries.

## 🛠️ Technologies Used

- Python
- Pandas
- Requests
- BeautifulSoup
- SQLite3
- Parquet

## 🎯 Objective

To strengthen practical Python skills in data loading, file conversion, web scraping, structured data storage, and database management through hands-on exercises.

## 🚀 Getting Started

1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install pandas requests beautifulsoup4 pyarrow
   ```

3. Open the Jupyter Notebook and run the cells to explore each concept.

## 📌 Learning Approach

This repository documents practical exercises and revision work focused on building a foundation in Python-based data processing and data engineering.
